# 一、游戏背景
玩家初始加入游戏，可以取一个名字，并加入魔法学院。并成为以卡牌作为施法媒介的魔法师。魔法师，可以在魔法学院中，学习成长。

# 二、游戏设定

**卡片系统：**
1. 攻击卡

- 火系：高伤害，有概率造成持续燃烧
- 雷系：高伤害，有概率麻痹敌人跳过下回合
- 水系：中等伤害，可冰冻敌人跳过下回合
- 风系：低伤害，可连击2次
- 土系：中等伤害，同时获得护盾

2. 防御卡

- 护盾卡：抵挡下一次攻击
- 反弹卡：将伤害反弹给对手
- 闪避卡：下回合攻击必定失误
 
3. 治疗卡

- 小治疗：恢复 x 点生命
- 大治疗：恢复 x 点生命
- 再生卡：连续 x 回合每回合恢复 x 点生命

**稀有度系统：**

- 普通卡（白色）：基础效果，魔力消耗1-2点
- 稀有卡（蓝色）：增强效果，魔力消耗2-3点
- 史诗卡（紫色）：强力效果，魔力消耗3-4点
- 传说卡（金色）：超强效果，魔力消耗4-5点

> 卡片越稀有，附带的能力越强

**装备系统：**
1. 魔法杖

- 初级杖：攻击+x
- 中级杖：攻击+x，魔力上限+x
- 高级杖：攻击+x，魔力上限+x，有5%暴击率
2. 魔法袍

- 学徒袍：生命+x
- 法师袍：生命+x，每回合恢复x点生命
- 大法师袍：生命+xx，减少xx%受到的伤害
3. 魔法饰品

- 护身符：附带 x % 概率闪避攻击
- 魔力戒指：每回合额外获得 x 点魔力
- 幸运项链：附带 x % 概率产生会心一击（正常供给 150%）
4. 卡包

- 基础卡包：
    - 3张卡槽
    - 只能承载普通卡
- 稀有卡包：
    - 5张卡槽
    - 可承载 普通卡，稀有卡
- 史诗卡包：
    - 7张卡槽
    - 可承载普通卡，稀有卡，史诗卡
- 传说卡包：
    - 9张卡牌
    - 可承载普通卡，稀有卡，史诗卡，传说卡

> 所有装备应该都有对应的等级，比如 传说的卡包，传说的魔法杖，传说的魔法袍，传说的火之卡片等，集齐相同等级的卡片可触发套装属性

**锻造系统：**

- 升级材料：
    - 锻造宝石
    - 升级材料
- 升级消耗表：


**角色系统：**

- 等级系统：最高30级，升级获得1属性点，属性点用于升级技能图谱（被动技能）
- 角色属性：
    - 生命：基础生命值 + 附加生命值
    - 魔法：基础魔法值 + 附加魔法值
    - 防御力：基础防御力 + 附加防御力
    - 防御率：基础防御率 + 附加防御率
    - 攻击力：基础攻击力 + 附加攻击力

> 附加的属性为装备附加的属性
> 伤害=(攻击力-对方防御力) * 暴击(无暴击 100%，暴击为(150+等级)%+装包附带)，伤害可能被闪避（防御率）
> 伤害扣除对方生命值，自己的魔法值
> 生命值： 100 + 等级*10
> 魔法值： 200 + 等级*20
> 基础防御力：1
> 基础防御率：1
> 基础攻击力：10

**地图：**

- 总地图：魔法学院
- 子地图：
    - 智慧之塔：理论学习。用于定期打卡，可获得经验值
    - 古籍图书馆：卡牌图鉴获取，限定与初中级的卡牌
    - 试炼之地：打怪获得经验值
    - 决斗竞技场：玩家对战主场地
    - 荣耀殿堂：排行榜与成就展示
    - 魔法工坊：装备锻造与升级
    - 魔法商店： 基础装备与道具购买
    - 拍卖行： 玩家间物品交易
